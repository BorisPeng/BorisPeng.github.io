比赛2026年10月8日

2026AIC 多模态视觉指代定位赛

给定可见光、红外、深度三路图像和一句文本描述，定位目标在画面中的边界框，完整走完数据、模型、评估到提交的比赛流程。

#多模态#目标检测#Grounding DINO#Qwen-VL

赛题与任务

第八届全球校园人工智能算法精英大赛的算法挑战赛道，赛题是“基于大模型的多模态视觉理解与推理”，我参与的是其中的视觉指代定位：输入同一场景的可见光、红外、深度三路图像和一句文本描述，输出目标在可见光图像中的边界框，按 ACC@0.5 计分。

这个任务和普通的检测不太一样：模型要读懂“楼梯旁那个半透明的玻璃穹顶”里指代的是哪一个物体，而三路图像能提供的信息各不相同——可见光给纹理，红外补夜间的轮廓，深度给空间关系。

我的做法

先把数据和评估口径固定下来。我把 RefCOCO 格式的标注整理成项目内统一的样本结构，另外构建了一份排除泄漏的固定验证集，保证每一轮实验都在同一把尺子上比较。

模型侧以 Grounding DINO 为主干，配合 Qwen3-VL 做单框定位和坐标解析；推理走两阶段流程，先粗定位、裁剪放大后再精修，多个候选框用引导框做集成选择。提交环节单独写了打包脚本，按官方模板生成 JSON 和 ZIP，并校验除 bbox 之外的字段没有被改动。

结果与复盘

最终拿到省级三等奖，止步复赛，没有进入国赛。现在回头看，最大的问题出在前期：对评测口径和候选框分布的理解花掉了不少轮次，真正有效的两阶段方案出现得偏晚，后面的时间只够验证，不够调优。

收获则集中在工程侧：第一次租用 GPU、第一次在服务器上管理多轮实验、第一次系统接触目标检测与视觉定位，也第一次把“看指标、改策略、再提交”拆成可复用的流程。仓库里只保留代码、测试和实验记录，数据集、模型权重和运行环境都没有入库，这也逼着我从一开始就把可复现性当回事。
